Example of running XookSuut3D on a datacube.

#Data: `example.halpha.cube.fits.gz`

This example is for the Halpha emission-line (rest frame 6562.68 AA).
The spatial resolution is 2.5 arcseconds
The spectral resolution is 160 km/s


USE: XS3D name cube.fits [mask] [pa] [inc] [xc] [yc] [vsys] vary_pa vary_inc vary_xc vary_yc vary_vsys ring_space [delta] rstart,rfinal cover kin_model [r_nc_min,r_nc_max] config_file [prefix]

type XS3D -h for help

# For running a circular model (`kin_model`=circular):
type a terminal type the following:
XS3D test example.halpha.cube.fits.gz None - - - - - 2 2 1 1 1 2 - 0,20 1/2 circular - xs_ha_test.ini

# For running a radial model (`kin_model`=radial):
type in the terminal type the following
XS3D test example.halpha.cube.fits.gz None - - - - - 1 1 1 1 1 2 - 0,20 1/2 radial 10 xs_ha_test.ini

# For running a bisymmetric model (`kin_model`=bisymmetric):
type in the terminal type the following
XS3D test example.halpha.cube.fits.gz None - - - - - 1 1 1 1 1 2 - 0,20 1/2 bisymmetric 10 xs_ha_test.ini


# For running a harmonic decomposition model up to m=2 (`kin_model`=hrm_2):
Note the harmonic order is complained with an underscore `hrm_n`, where n is the harmonic order.

type in the terminal type the following
XS3D test example.halpha.cube.fits.gz None - - - - - 1 1 1 1 1 2 - 0,20 1/2 hrm_2 10 xs_ha_test.ini
